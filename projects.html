FLINT WiFi Voucher Website

Designed and developed a website to automate sale and distribution of Wi-Fi vouchers for a local ISP. Integrated Paystack for secure payments, used Supabase for voucher storage, and implemented email delivery of vouchers. Built with Node.js, Express, Supabase, and vanilla JS.

Key features: Paystack payments, voucher generation, Supabase-backed storage, responsive UI, email delivery.

Serious Gamers Tournament Website

Tournament registration and bracket site with team registration, slot limits, and Supabase for data persistence. Responsive frontend with admin management features.

Key features: Team registration, bracket display, admin controls, Supabase integration.

Arduino Traffic Light Control System

Embedded systems project using Arduino Uno to implement traffic-light cycles. Programmed timing logic in C/C++, simulated and tested with Proteus.

Key features: Hardware interfacing, timing logic, Proteus simulation.
